# Python Day 164 – Server Log Analyzer

## Project Description
A Python-based Server Log Analyzer that reads server log files and generates a report about website requests, HTTP status codes, IP addresses, and frequently accessed URLs.

## Features
- Counts total server requests.
- Identifies successful requests.
- Detects client and server errors.
- Displays HTTP status code statistics.
- Finds the top 3 active IP addresses.
- Finds the most requested URLs.

## Technologies Used
- Python
- Regular Expressions
- File Handling
- Collections Counter

## Files
- `log_analyzer.py` – Main Python program.
- `server.log` – Sample server log data.

## How to Run
1. Download or clone this repository.
2. Keep both files in the same folder.
3. Open a terminal in that folder.
4. Run `python log_analyzer.py`.

## Learning Outcome
Learned how to process log files, extract information using regular expressions, count data, and generate a basic server activity report.
